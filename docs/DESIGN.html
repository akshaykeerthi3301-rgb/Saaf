Typography

Public Sans throughout — the typeface of United States civic notices, chosen because a product that publishes its own arithmetic should be set in the type of an official document. JetBrains Mono carries every number.

Spacing

An 8px base. The reference site's irregular 15px and 18px paddings were normalised onto this scale rather than copied.

Radius

Corners are square. The reference contained no rounded rectangles at all. md, lg and xl are omitted on purpose, so no future screen can quietly drift toward the consumer-app default.

Elevation & Depth

There is none. The reference returned an empty set for box-shadows across every element, and that is reproduced exactly. Depth is one hairline and one lighter surface.

Do's and Don'ts

Do
  • ✓Show the arithmetic. Every count that narrows is a sequence, never a single total.
  • ✓Show the working — every score with the components behind it and the sentence each was read from. A number never appears alone.
  • ✓Attribute thinness to coverage, never to the candidate.
  • ✓Use rows and hairlines for the role list; cards only for self-contained objects.
  • ✓Set every number in numeric-md with tabular numerals so columns align.
  • ✓Keep the reason line adjacent to the score, always.
Don't
  • ✗Don't use error red for a match outcome. A low score is a correct answer, not a failure.
  • ✗Don't add a shadow — not one. The anti-reference has 196; this system has zero.
  • ✗Don't round a corner beyond the 2px reserved for inputs. No pills — the anti-reference has 473.
  • ✗Don't introduce a second chromatic accent, and never a Tailwind default green/red/amber trio.
  • ✗Don't render a score without its reason — that's the exact failure this product corrects.
  • ✗Don't build a dashboard. One column, one document.
